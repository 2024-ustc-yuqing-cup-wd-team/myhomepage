What's inside

Two tools, one start page

No account, no database, no tracking. Your links and events never leave your browser.

Bookmarks

Pin the campus systems you open every day — the academic portal, webmail, Blackboard, 瀚海 — and reach any of them in one click. Each bookmark gets a colour-coded monogram, and the list is capped at ten to stay tidy.

Open bookmarks →

Calendar

Month, week and day views, click-to-create events, and edits that survive a refresh. Powered by FullCalendar and persisted in localStorage, so there is nothing to sign up for.

Open calendar →

Architecture

Static first, self-hosted when you want

The site is plain HTML, CSS and JavaScript, so it can live on GitHub Pages or on an Orange Pi behind Nginx. An optional Express service provides a health endpoint and a home for future APIs.

Quick start

No build step

Clone the repository and serve the folder with any static file server.

git clone https://github.com/2024-ustc-yuqing-cup-wd-team/myhomepage.git
cd myhomepage
python3 -m http.server 8000
# open http://localhost:8000

Deploying on an Orange Pi instead? The orangepi-server repository has the Nginx configuration, systemd unit and a one-shot bootstrap script.
