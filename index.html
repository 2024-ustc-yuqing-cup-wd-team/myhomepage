The tools

Two small things, done carefully.

Bookmarks for the ten tabs you reopen every day; a calendar for the week you keep rewriting. Both live entirely in your browser.

Principles

Quiet software, by design.

  1. 01

    Local by default

    Bookmarks and events live in localStorage. There is no database, no sync, and nothing to export before you close the tab.

  2. 02

    No accounts

    No sign-in, no tracking pixels, no analytics. The page makes zero third-party requests while it runs.

  3. 03

    Runs offline

    Fonts, icons and the calendar are served from this repository, so it still works on a LAN with no internet.

Colophon

Hand-written HTML, CSS and JavaScript. Typeset in Instrument Serif and Inter, both self-hosted. The calendar is FullCalendar. The site is published from this repository with GitHub Pages; the original deployment ran on an Orange Pi behind Nginx.
